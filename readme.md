# Underwater Fish Detection Dataset VOC+YOLO format with 2303 images in 1 category

Dataset format: Pascal VOC format + YOLO format (txt file without split path, only containing jpg images and corresponding VOC format xml files and yolo format txt files)
Number of images (number of jpg files): 2303
Number of annotations (number of xml files): 2303
Number of annotations (number of txt files): 2303
Number of annotation categories: 1
Annotation category names: ["goldfish"]
Number of bounding boxes per category:
goldfish bounding box count = 7132
Total bounding box count: 7132
Labeling tool used: labelImg
Annotation rules: draw a rectangle around the category
Important note: No guarantee is made regarding the accuracy or weights of the trained model. The dataset provides accurate and reasonable annotations only.
